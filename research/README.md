## Retained evidence

Numbered reports are historical research, not current product documentation. `evidence/` contains downloaded third-party originals and is ignored by Git. `results/` retains original experiment inputs, receipts, failures and observations. `notes/archive/` holds earlier handoffs. Open those only for a specific historical question.

Routine verification output belongs in ignored `test-artifacts/`. Do not create copies of the evidence tree. Older task reports removed during cleanup are recoverable with `git show 4622b0f:docs/<filename>.md`. Historical links to that commit refer to the local snapshot, which has not been pushed by this task.
