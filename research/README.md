## Reproduce the evidence work

```powershell
node research/scripts/extract-plugin.cjs research/evidence/plugin/installed-68657693815716.rbxm research/evidence/plugin/source
node research/scripts/build-offline-probes.cjs
& research/tools/luau/luau.exe research/tests/offline-probes.luau
```

The extractor verifies decompressed chunk sizes and stores hashes and instance paths in [the manifest](evidence/plugin/source/manifest.json).
