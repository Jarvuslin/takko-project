# B foundation with a more capable canvas

Apply the selected B visual language to the real project workspace. Borrow clearer runtime and connection hierarchy from C, and place the inspector below the canvas in normal document flow. Preserve the real project, model, budget, graph, chat and Studio behaviors.

## Scope

- In: project-only icon rail, spacious inset agent panel, larger graph, readable nodes and labeled connections, docked inspector, desktop/mobile regression and visual checks.
- Out: backend changes, paid generation, Studio operations, new dependencies, changing the approved lab comparisons or redesigning the Models and Presets pages.

## Visual decisions

Keep B's 76px rail, warm monochrome surfaces, 16px agent inset, soft 18px radius, 15px prose and low-border activity presentation. Give the canvas the remaining width beside a 400px agent panel at 1440px. Use a compact heading and toolbar so the graph gains vertical space. Nodes retain B's soft shape but separate runtime, system name, status and ports. Connections get centered, high-contrast event labels. The inspector occupies a bounded bottom row, with details and connections in columns, instead of overlapping the graph. It collapses completely when closed. Mobile keeps graph and conversation in one bounded screen, with more room for the canvas while inspecting.
