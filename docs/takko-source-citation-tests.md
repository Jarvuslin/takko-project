# Component source citations

The V8 Gemini review and a subsequent frozen GPT-5.6 Sol diagnostic both failed because they joined separated lines into a supposedly exact quotation. Sol repeated the same splice during automatic correction. Increasing model cost did not solve that observed failure; [the preserved comparison](../research/results/source-review-sol-v1/RESULTS.md) records both attempts and all charges.

`component-review.ts` now accepts one of two strict dependency citation forms: an exact legacy `sourceQuote`, or `sourceLines: { start, end }`. Ranges are inclusive, one-based, contiguous and tied to the enclosing source hash. Validation extracts from the immutable original source, preserving CRLF, CR, LF, indentation and Unicode. Empty, reversed, fractional, missing, out-of-bounds or overlong citations are rejected. A citation must be nonblank and at most 1,500 characters. Supplying both citation forms is rejected.

Engine source reviewers see every source line once, with line numbers; stored evidence retains the original body. Validation never uses displayed line numbers as numeric asset evidence. Existing ID/configuration, source/media/requirement/permission coverage and disposition rules remain in force. The raw worker-selected citation is saved without turning it into a rewritten review, including through integration persistence and reload. Failure feedback identifies the source hash and dependency index. Sound-listening routing is unchanged.

Offline checks cover exact extraction, malformed ranges, invented IDs, source identity, unchanged historical quote rejection, model schema, real Engine handoff and persisted integration reload. Focused checks passed 205 tests and TypeScript. Full `npm run check` passed 1,048 unit/API, 10 desktop and 36 browser tests plus every other stage. The [fresh Gemini diagnostic](../research/results/source-review-lines-v1/RESULTS.md) passed the citation contract on its first attempt for $0.050034, using eight line ranges. Independent semantic review remains partial: unsupported intent/layout/duplicate-protection claims and incomplete dependencies remain. Its protocol was written before dispatch.

The fresh paid test uses the unchanged V8 captured component and game context, with the deliberately changed review interface. It provides no earlier answer or authored replacement to the worker. Contract validity, independent semantic assessment and actual native gameplay remain separate. No diagnostic review is injected into a failed game project, and this host-side citation change itself does not establish a finished game.
