## Additional defect found by visual verification

The first actual packaged dummy preview showed only a grid, despite passing the canvas-presence assertion. Imported primitive parts set their matrices directly. Camera bounds were calculated before updating world matrices, so the camera framed the origin while the asset remained at its authored coordinates near237,0,120. The shared viewport now updates world matrices before fitting the camera and centers the grid beneath the asset. Verification now requires rendered triangles, not just an allocated canvas. Native1 and native2 screenshots remain preserved as evidence of the defect. Native2's interaction pass does not establish visible dummy geometry.

## Implemented

- One focus-modality policy replaces the competing global focus rules. Mouse clicks suppress the ring, while keyboard navigation gets a two-pixel muted blue indicator. Text-field browser heuristics no longer decide mouse focus styling. Hidden native question radios retain row-level keyboard focus.
- SettingsDialog renders at the app root so chat-card styles cannot leak into it. Its opt-in scroll body provides a shrinking flex child with `min-height: 0`, bounded overflow, and independent header/footer. Nested modals share a counted body-scroll lock and restore focus without scrolling their trigger. Existing Add Model and preset forms retain their working body/footer structure.
- Important structured questions open a compact Question dialog. Numbered choices, custom responses, Back, Next and Send retain native form semantics. Optional questions alone expose Skip. Simple choices remain inline, normal chat remains chat, and completed answers appear as a compact editable receipt.
- Both asset browsers use the source's actual 30-item pages. The server follows Roblox cursors rather than synthesizing page offsets. Project choices retain all loaded candidates, deduplicate overlapping pages and reject stale/mismatched cursors. Query changes start a new result set. Browsing never approves the first result.
- Each source page batches its detail lookup. Duplicate requests coalesce, successful pages cache for five minutes with 100-page capacity, and network failures are not automatically retried. Actual visible up/down vote counts drive the displayed percentage and count. Hidden/unavailable votes stay unavailable and zero votes say No votes yet. Non-free or wrong-type detail rows are excluded.
- The chooser shows one asset group at a time with compact thumbnail cards, one Select action and an explicit selected state. Static thumbnails load in bounded 20-ID batches shared with Marketplace. Preview opens a separate dialog, leaving the result DOM, pages, group, query and scroll position intact. Only the active preview mounts a renderer. Clip navigation is independent of selection. Choose this asset and Remove selection are available inside preview. Approval remains a separate action.
- The renderer updates authored world transforms before calculating camera bounds, aligns the grid beneath the model, and releases the WebGL context on both unmount and factory failure.
