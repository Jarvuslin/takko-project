# Source map

- `src/generation/`: planning, provider routing, budgets, generation, validation and export.
- `src/marketplace/`: Creator Marketplace discovery, selection and asset adapters.
- `src/server/`: local API and Studio bridge.
- `src/web/`: desktop interface.
- `desktop/`: Electron packaging, service supervision and window policy.
- `plugin/Forge.plugin.luau`: Roblox Studio plugin.
- `native/audio-capture/`: Windows audio capture helper.
- `tests/`: offline regression fixtures, browser journeys and native test helpers.
- `benchmarks/`: benchmark definitions and starting fixtures.

See [desktop setup](desktop.md) for packaging and data storage, and the [root README](../README.md) for development commands.
