# Included Marketplace audio before a separate search

2026-09-16. V7's stronger plans asked to source separate audio only when retained components lacked suitable media, but the pipeline always searched. Takko now offers exact captured sounds from the components retained in the current run before issuing a separate Audio search. The worker still chooses the candidate or requests a Marketplace search. No need is skipped or considered satisfied from a SoundId alone.

The adapter reopens immutable integration records and revalidates component need, scope, current adapter ownership, input/source/archive identities, reviewed media and confirmed quarantine cleanup. Only canonical asset references on captured Sound-class SoundId properties are candidates; dynamic source strings, arbitrary URLs and animation IDs are excluded. Equal IDs are grouped with their original binding indices. Twenty candidates are offered at most. Parent Marketplace provenance is explicit; audio creator and separate listing price remain unknown. Duplicate IDs across retained components do not overwrite an earlier offer, and registration remains scoped to the Audio need.

The pipeline records discovery calls/results and offered origins, validates them against the current run's retained component, and supplies them through the normal decision context. Embedded discovery consumes no Marketplace search allowance. A worker retry executes its own chosen query; attempts and rejected-ID exclusions remain bounded. Ordinary search results cannot impersonate embedded provenance. Native inspection, playback capture, listening evaluation, separate placement capture/evaluation and cleanup are unchanged. Read-only discovery failures halt honestly without falsely claiming an uncertain Studio mutation.
