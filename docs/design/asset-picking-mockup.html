Row states

  • Not chosen. Nothing picked yet. Approve & build names this row.
  • Checking. Takko inspects the asset. For animation packs it also loads the clips through the Studio plugin.
  • Ready. Free, the right type, inspection passed, and a clip chosen for animations.
  • Check this pick. Usable, but something looks off (name mismatch, scripts inside). One click to keep it.
  • Problem. Verification failed. The reason and a fix sit in the row.

Choose for me

  • Searches the need's words, judges relevance on the first page with the cheap relevance model, picks the best match, then verifies it.
  • Shows the pick and one line on why. You can change it.
  • If nothing fits, the row stays empty and says so. It never grabs a random asset.
  • Cost shows before it runs and counts against the project cap.

Marketplace in picking mode

  • Opens on the left with a "Choosing: …" banner, the search prefilled and editable.
  • Results in the same order as the Creator Store website. Anything filtered out is counted above the grid.
  • Results show immediately. Inspection only runs for the asset you pick.
  • Excluded assets stay visible but can't be used.

PC only by default

  • Games target keyboard and mouse unless you ask for mobile, console or VR.
  • No touch buttons, gamepad bindings or tap wording unless requested.
  • The platform shows on the project, like the chip on the map above.
