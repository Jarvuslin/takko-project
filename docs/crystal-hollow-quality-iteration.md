## New authored scenario

`scripts/polished-generation-spec.ts` defines Crystal Hollow: a compact crystal quarry with visible terrain, paths, terraces, an arch, six crystal clusters, sell/upgrade stations and a beacon. The player collects and sells crystals, chooses between pick-power and bag-capacity upgrades, and works toward a personal beacon-restoration goal. Shared node stock and private player economies have explicit interfaces. Seven Luau files are assigned to five tasks.

Static world geometry must exist in the exported scene before Play. The scene-entry limit bounds generation output size; it is not a visual-quality score. All assets are procedural, with no fabricated uploaded IDs or added monetization/persistence/audio requirements.

This is an authored test brief and contract, **not a demonstration of model-generated planning**. Game implementation is generated by the configured model; the exact output must be evaluated independently.
