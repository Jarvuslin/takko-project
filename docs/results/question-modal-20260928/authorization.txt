## What the user wants

When the run needs an answer, a modal pops up in the workspace, like a ChatGPT/Claude question prompt. It is not buried in the proposal text. Each question shows:
- A clear, specific question in plain words, for example "How should punching work?", not "Should this limit apply?".
- Up to 3 concrete choices, each with a one-line description of what it means for the game. For example: "Single punch: one attack on click", "2-hit combo: jab then cross, press again within 0.5s", "3-hit combo: jab, cross, hook".
- One choice marked "Recommended", with a short reason.
- An "Other" option with a text box where the user types their own answer.
- Multiple questions step through one at a time (question 1 of 3), with back and next, and a final review before submitting.
- The modal can be closed and reopened from a visible "N questions need answers" badge or button. It is never a dead end.
- Keyboard accessible, focus trapped, Escape closes, works at mobile width. Use the existing tokens.css. No external fonts.
