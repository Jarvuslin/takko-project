# Bounded component repair

V12 reached post-adaptation review and correctly rejected a worker-authored reset race. Takko previously stopped after that first adaptation. It now offers the worker one repair using the actual review and current captured sources, subject to the existing monetary budget. There are at most two adaptations per candidate. An accepted first adaptation proceeds; an unsuitable verdict, rejected repair, invalid output, cancellation or uncertain native outcome does not create another opportunity.

The repair loads its immediate parent archive through a chain anchored to the immutable prepared component. Each record, plan, input identity, parent archive and resulting inventory is checked. Original records and single-hop formats remain unchanged. The native adapter uses separate capture slots and consumes an attempt before dispatch; a failed edit cannot be retried or integrated using an older head. Historical runtime-only markers are mapped from original parents through both edits.

Review context keeps original, parent and current source snapshots distinct. Plans reference source hashes instead of repeating source bodies. Only current evidence authorizes edits and current-source citations. Original-to-current mappings keep successive edits from concealing lost behavior. Pending media audition, central UI/counter work and native testing remain explicit integration obligations; actual unsafe behavior or unresolved executable dependencies still block acceptance.
