# Takko taco mascot

Original vector mascot with a golden shell, green lettuce, coral tomato pieces, rosy cheeks and a small smile. Drawn directly in SVG for crisp rendering at app-icon sizes. No external artwork or image service was used.

The canonical editable source is [public/takko.svg](../../public/takko.svg). Both app placements and the browser favicon use that same file. [taco.png](taco.png) is a transparent 320px export for preview and reuse.

The mascot uses warm color against Takko's existing monochrome interface. It is decorative in the UI, with the existing accessible home-link name retained.
