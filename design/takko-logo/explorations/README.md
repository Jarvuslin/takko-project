# Takko logo explorations

[Open the editable Figma board](https://www.figma.com/design/YfjtZOJSKgn85oXSE1NsY5/Takko?node-id=2-2).

Six original directions: Mochi, Fold, Peek, Sprout, Byte and Amigo. Each has a standalone SVG and transparent 512px PNG. The 1440 by 1200 comparison board includes wordmarks and 16, 24, 28 and 32px samples. Peek switches to a dark silhouette in the light-background comparison.

Recommended shortlist: Mochi for the cute mascot direction, Peek for a quiet monochrome assistant. These are proposals. The running app still uses its existing taco mascot.

The board was imported through Figma's browser editor as a frame with named groups, vectors and text layers. It is not a flattened PNG or a published component library. Figma MCP remains quota-limited, but browser import succeeded and was visually verified.

Visual references studied: [Linear](https://linear.app/brand), [Raycast](https://www.raycast.com/press), [Discord](https://discord.com/branding), [Claude](https://claude.com/product/overview), and Linear's [Discord](https://linear.app/integrations/discord) and [Raycast](https://linear.app/integrations/raycast) logo comparison graphics. Borrowed principles are compact silhouettes, restrained color, expressive faces and organic shapes. No reference logo was traced or incorporated into these assets.

Rebuild with `node design/takko-logo/explorations/build.mjs`. Run `node --test design/takko-logo/explorations/verify.mjs`. The renderer uses the existing bundled Sharp runtime on this workstation.
