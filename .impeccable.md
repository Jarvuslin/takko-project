## Design Context

### Users
Roblox creators describing games and refining them before generation. User-provided references: Lemonade and Cursor. The requested workflow includes questions, asset choices, HUD previews, approval and verified builds.

### Brand Personality
Working direction: capable, calm, creative. Provisional name Forge. These are implementation defaults, not finalized user branding.

### Aesthetic Direction

Typography refinement (2026-09-14): user explicitly requested the Bugatti getdesign.md/GitHub typography while preserving the existing UI. Use its documented open-source substitutes: Saira Condensed regular display, EB Garamond prose, JetBrains Mono controls/metadata. Keep the existing palette, layout and components; further work is typography or polish only unless requested otherwise.
Current direction (2026-09-14): copy the observed Lemonade dashboard and workspace structure. Cyan/blue atmospheric dashboard, condensed white/yellow heading, dark rounded composer, charcoal navigation. The project uses a dotted dark task canvas and a right-side conversation panel. See `research/15-authenticated-workspace-ui.md`. Earlier light/green styling was rejected.

### Design Principles
1. Show the next meaningful creator decision.
2. Give the design canvas space; keep implementation detail in build/file views.
3. Distinguish browser studies, generated artifacts and Studio verification.
4. Use keyboard-accessible controls, visible focus and responsive layouts.
5. Keep a compact, approachable workflow with explicit supported scope.

### Revised direction after rejection (2026-09-13)

The user rejected the initial light combat-only screen. Forge 0.2 uses a restrained dark workspace inspired by their Cursor reference, readable hierarchy, and separate brief/build/source/Studio views. Game previews must be actual Studio observations; do not reintroduce decorative SVG arenas as generated output. Genre suggestions are editable prompts, never fixed game templates.
